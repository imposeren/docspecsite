# docspecsite

docspecsite checks a repo's docs and renders every version of every doc from git history to a static site.

This project is documentation-driven: `docs/` is the spec ([docs/index.md](docs/index.md)).
It was created from [docs-driven-template](https://github.com/imposeren/docs-driven-template) with Copier; `.copier-answers.yml` records the template version and the answers.
