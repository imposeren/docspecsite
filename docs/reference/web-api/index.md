# HTTP API reference (generated)

The web API's contract is its **schema**, a machine-readable description of its HTTP endpoints.
It is **committed to the repo**, so every change to the API shows up as a diff, and its git history gives the API's versions.
The docs build renders each version as a reference page.

In raw form, read the committed schema file directly; the project's architecture docs say where it lives.
A `web-api:<operationId>` link refers to one endpoint by its operation id.

No web API exists yet, so there is no schema or rendered page.
